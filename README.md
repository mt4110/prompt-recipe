# prompt-recipe

AIを使ったソフトウェア開発の進め方を、実例とレシピで実践しながら学ぶためのローカル中心のデスクトップツール。

自分の作業原則・プロジェクトの前提・今回の依頼を組み合わせ、別のAIやPCでも説明し直す手間を減らす。教材は検証とフィードバックに基づいて更新する。

V0.1のローカル実装あり。AI比較と渡す環境・用途を選ぶ入口を追加し、選択に応じたMarkdown/XML出力を利用できる。比較資料は2026-10-04の公式情報を照合したスナップショット。

通常画面・小窓・3段階のオンボーディング、変数展開、構造化衝突検査、SQLite保存、版とフィードバック、JSONの入出力を利用できる。教材は効果未検証の候補。設計全体の完成・公開版ではない。

## ローカルで起動

Node.js 26、Rust、macOSではXcode Command Line Toolsを使用。

```sh
npm ci
npm start
```

グローバルキーはmacOSでCmd+Shift+Space。他OSではCtrl+Shift+Spaceを登録する（他OSは未検証）。

```sh
npm run build
npm run test:core
```

ブラウザで操作を確認する場合は `npm run preview:core` の後、`PROMPT_RECIPE_PREVIEW=1 npm run dev`。Viteは127.0.0.1:1420を使用する。ブラウザとネイティブの開発起動を同じポートで重ねない。ブラウザ用DBは `.local/preview.sqlite`、実機のDBはOSのアプリデータ領域。

[実装と確認状況](docs/IMPLEMENTATION.md)に、検証済み・未検証・未実装の区別を記載。

## 台帳から使う

起動後は「プロンプト台帳」が入口。初回案内は3段階で、スキップ・再表示できる。名前と本文だけで自分の指示を登録し、変数がある場合だけ入力してコピーする。「組み込み教材」は別の一覧から選べる。

複数の指示はチェックした順番で合成し、名前付きセットとして保存する。「プロジェクトを開く」でGit作業ツリーのルートを選び、セットを適用して「このセットを保存」すると小窓へ反映される。通常の`.git`ディレクトリとworktreeの`.git`ファイルに対応し、非Gitフォルダやルート以外は拒否する。Gitには読取専用の検証コマンドだけを実行し、プロジェクトのファイルを自動で読んだり変更したりしない。以前の個人作業領域は保持する。

小窓を開くと通常画面を隠し、通常画面へ戻ると小窓を隠す。入力は各画面内に保持する。小窓のEsc・コピー成功は小窓を隠し、通常画面は自動表示しない。macOSで両窓が隠れた場合はDockから通常画面へ戻れる。プロジェクト変更後は新しい割り当てへ切り替わる。

## PCを変える・セットを渡す

「台帳をExport」は全版と採用版、名前付きセットをJSONへ保存する。セットごとのExportは固定した版と派生元を含み、合成順を保持する。OSの保存ダイアログで**新しいファイル名**を選ぶ。既存ファイルは上書きしない。

新PCの「台帳・セットをImport」でJSONを選び、本文と変更内容を確認して導入する。旧形式schema 1/2も受け付け、新しい台帳・セット形式はschema 3。同じ版IDの内容変更、参照不足、循環、同じセットIDの異なる内容は拒否する。新しい既存版とプロジェクトの固定版を保持し、導入はトランザクションで行う。上限はファイル1 MiB、512版、128セット、セット内32版。

Exportにプロジェクト情報、PC固有のパス、今回の入力、クリップボード素材、利用履歴、フィードバックは含めない。**保存した本文自体に秘密や案件情報があればJSONに含まれる。JSONは平文**。Gitプロジェクトは移行先で開き直す。他OSのアプリ動作まで保証するものではない。

ZIPとマルウェア検査は未実装。[検査境界の設計](docs/ZIP-SAFETY.md)を用意した。JSON Importの形式検証はマルウェア検査ではない。

## ローカル処理・性能・保存の境界

分類検索はUI内、連続入力の合成は120msに集約。小窓は初回利用時だけ生成し、隠れたページのReact効果は停止する。同梱AI資料は解析結果を再利用し、SQLiteは上限32件の専用ワーカーで処理する。定期ポーリング、常時クリップボード監視、実行時の外部AI呼び出し、テレメトリー、自動同期は含めない。コピー時の再検査は維持する。

XML文書とMarkdownの基本Lintは明示操作でローカル実行する。XMLはタグ・属性・参照・ルート等を確認し、DTDを拒否する。Markdownは見出し段差、行末空白、未閉鎖コードフェンスを扱う。全文の規格適合、指示の意味、AIの遵守は保証しない。Lintは助言であり保存・コピーを強制停止せず、本文を自動修正しない。

CSP・IPC権限・外部ナビゲーション拒否・開発通信のガードを回帰チェックする。これはアプリの通信境界であり、OS全体の情報漏洩を防ぐDLPではない。SQLiteは暗号化しておらず、明示ExportやOSクリップボード、利用者によるAIへの貼り付けは別の送信経路になる。

2026-10-08のdebugビルドは.app約49.35 MiB、JS約274.18 kB（gzip約84.58 kB）。ファイルサイズであり、実行時メモリや消費電力ではない。CPU、WebViewを含むメモリ、IPC往復、消費電力の比較測定は未実施。省エネ率・性能改善率は主張しない。

ビルド済み.appを作る場合：

```sh
npm exec tauri build -- --debug --bundles app
```

生成先は`src-tauri/target/debug/bundle/macos/Prompt Recipe.app`。ローカル確認用debug版で、配布用署名・公証は未実施。Windows `.exe`、証明書購入、インストール用CLIは判断待ち。`npm start`は準備済み開発環境の一発起動で、配布済みバイナリのインストールコマンドではない。
